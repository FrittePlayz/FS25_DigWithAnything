# Dig With Anything (FS25)

**TerraFarm configs for the machines you already own.** 🚧 *Work in progress — nothing to download yet.*

🇩🇪 [Deutsche Fassung weiter unten](#dig-with-anything-de)

## The problem

Getting started with [TerraFarm](https://github.com/scfmod/FS25_TerraFarm) means hunting down machines first. TerraFarm only works with vehicles that carry a machine configuration — and the official machines add-on covers third-party mods, as do the community packs. Nobody covers what the game already gives you.

So the usual first evening with TerraFarm goes: install it, notice nothing happens, search for a machines add-on, find out it needs modded excavators, download a Cat D11, and only then move the first bucket of dirt.

## The plan

A configuration add-on that makes machines TerraFarm-capable without you editing anything:

1. **The base game fleet first** — wheel loaders, telehandlers, front loaders, and their buckets, blades and ripper attachments. Install, take the loader that's already in your shed, start digging.
2. **Then anything else** — the goal is to detect suitable equipment at runtime from what it *is* (bucket, blade, shovel) rather than from a hand-written list, so machines nobody has configured yet still work. That's where the name comes from.

No third-party mod files are modified or shipped — configurations only, pointing at machines you installed yourself.

## Status

Early. This repository exists so the idea is public and so machine requests can be collected — **if a machine should work with TerraFarm and doesn't, [open an issue](../../issues)** and name it. That list will shape what gets built first.

# Dig With Anything (FS25) 🇩🇪

**TerraFarm-Konfigurationen für die Maschinen, die du schon hast.** 🚧 *In Arbeit — noch nichts zum Herunterladen.*

## Das Problem

Wer mit [TerraFarm](https://github.com/scfmod/FS25_TerraFarm) anfangen will, muss sich erst Maschinen besorgen. TerraFarm arbeitet nur mit Fahrzeugen, die eine Maschinen-Konfiguration mitbringen — und das offizielle Machines-Addon deckt Fremd-Mods ab, die Community-Packs ebenso. Niemand deckt ab, was das Spiel ohnehin mitbringt.

Der erste Abend mit TerraFarm läuft deshalb meist so: installieren, merken dass nichts passiert, Machines-Addon suchen, feststellen dass es Mod-Bagger braucht, einen Cat D11 herunterladen — und erst dann die erste Schaufel Erde bewegen.

## Der Plan

Ein Konfigurations-Addon, das Maschinen TerraFarm-fähig macht, ohne dass du etwas editierst:

1. **Zuerst die Basisspiel-Flotte** — Radlader, Teleskoplader, Frontlader samt Schaufeln, Schilden und Reißzähnen. Installieren, den Lader aus der eigenen Halle nehmen, graben.
2. **Danach alles andere** — Ziel ist, passendes Gerät zur Laufzeit daran zu erkennen, *was* es ist (Schaufel, Schild, Löffel), statt an einer handgepflegten Liste. Dann funktionieren auch Maschinen, die noch niemand konfiguriert hat. Daher der Name.

Es werden keine fremden Mod-Dateien verändert oder mitgeliefert — nur Konfigurationen, die auf selbst installierte Maschinen zeigen.

## Stand

Früh. Dieses Repository existiert, damit die Idee öffentlich ist und Maschinen-Wünsche gesammelt werden können — **wenn eine Maschine mit TerraFarm arbeiten sollte und es nicht tut, [mach ein Issue auf](../../issues)** und nenne sie. Diese Liste bestimmt, was zuerst gebaut wird.
